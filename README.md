# 165反詐記憶大作戰

這是一個單頁 HTML 互動式記憶卡片遊戲，適合部署到 GitHub Pages。

## 專案內容

- `index.html`：主程式，已內嵌樣式與圖片素材，可直接開啟或部署。
- 適合使用 GitHub Pages 靜態網站部署。

## 本機預覽

直接用瀏覽器開啟 `index.html` 即可。

## GitHub Pages 部署方式

1. 將本專案上傳到 GitHub repository。
2. 進入 repository 的 `Settings`。
3. 選擇 `Pages`。
4. Source 選擇 `Deploy from a branch`。
5. Branch 選擇 `main`，資料夾選擇 `/root`。
6. 儲存後等待 GitHub 產生網址。
